# NSYSU Academic Opportunities

One-page academic recruitment website for National Sun Yat-sen University.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Unzip this package and upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

GitHub will display the published website URL after deployment finishes.
